# Audio Feature Catalog

Prototype categories for recording-based analysis:

## Tempo And Pulse

- estimated tempo
- onset density
- beat stability proxy

## Spectral Shape

- spectral centroid
- spectral bandwidth
- rolloff
- flatness

## Timbre

- MFCC summaries
- zero crossing rate
- RMS energy
- dynamic range proxy

## Tonal Content

- chroma balance
- tonal centroid summary
- key stability proxy

## Structure

- self-similarity contrast
- section count estimate
- novelty peak count
