# Symbolic Feature Catalog

Prototype categories for notation-based analysis:

## Melody

- pitch range
- mean interval size
- stepwise ratio
- leap ratio
- contour change count

## Rhythm

- note density
- duration entropy
- syncopation proxy
- rest ratio

## Harmony

- chord change rate
- chromatic pitch ratio
- cadence proxy
- vertical interval balance

## Voice Leading

- parallel motion proxy
- contrary motion proxy
- voice crossing count

## Form

- phrase length estimate
- repetition ratio
- sectional contrast proxy
