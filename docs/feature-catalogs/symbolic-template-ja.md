# symbolic 共通テンプレメモ

このメモは、どの `symbolic` データにも使い回せる分析テンプレを日本語で整理したものです。

## 目的

`symbolic` 分析では、まず「音楽が何でできているか」ではなく、
「記号表現に何が書かれていて、そこから何を計算できるか」を整理します。

## 共通ルート

1. 入力ファイルをパースする
2. 音符イベント列に正規化する
3. 声部別系列、onset 別スライス、小節別系列などの派生ビューを作る
4. そのビューから特徴量ファミリごとに値を計算する
5. 1 曲 1 行の特徴量表へ落とす
6. 列の意味を読むための特徴量辞書も同時に出力する

## 構成要素の 3 層

| 層 | 内容 | 例 |
| --- | --- | --- |
| 記載済み要素 | ファイルに直接書かれているもの | 音高、音価、開始位置、パート、小節 |
| 導出要素 | 関係から計算できるもの | 音域、音程、密度、同時発音、厚み |
| 推定要素 | 理論やルールで後から推定するもの | 調、和声機能、終止、フレーズ |

## 現行テンプレの主な出力列

| 列名 | 意味 |
| --- | --- |
| 曲ID | 曲の識別子 |
| 元ファイル名 | 入力ファイル名 |
| 特徴量ソース | どの抽出系で作ったか |
| 音符数 | 音符イベント総数 |
| パート数 | パートや声部の種類数 |
| 全体音域 | 曲全体の最高音と最低音の差 |
| 平均音高 | 音高平均 |
| 音高ばらつき | 音高の散らばり具合 |
| 主旋律音域 | 主旋律系列の音域 |
| 主旋律平均音程幅 | 主旋律の隣接音どうしの平均距離 |
| 主旋律順次進行率 | 2 半音以内の進行比率 |
| 音符密度 | 単位時間あたりの音符数 |
| 平均音価 | 音価平均 |
| 音価エントロピー | 音価の多様さ |
| 発音開始点数 | onset の種類数 |
| 同時発音率 | 複数音が同時に鳴る割合 |
| 平均発声音部数 | onset あたりの平均発声音部数 |
| 最大発声音部数 | もっとも厚い onset の声部数 |
| ピッチクラス種類数 | 12 音クラス上の使用種類数 |
