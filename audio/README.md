# audio

録音音源を対象にした音楽分析プロジェクトです。

## 目的

次のような研究や探索に使える、再利用可能な音響特徴抽出・分析基盤を作ることを目指します。

- 楽曲のまとまりやクラスタの探索
- ジャンル感や雰囲気の分析
- 類似曲比較やマッシュアップ相性の検討
- ボカロ曲を含む音源ベース研究

## 現在のスコープ

- 当面は `librosa` 系の基本音響特徴を想定
- まずは教師なし寄りの探索から始める
- 研究用途にも趣味用途にも流用しやすい設計にする
- 音源分離や大規模モデルは後回しにする

## 入力

- wav
- mp3
- 必要に応じてその他の一般的な音源形式

## 出力

- 1 曲 1 行の音響特徴量表
- 可視化やクラスタ分析の土台
- 類似曲比較や相性評価につながる基盤

## 現在のプロトタイプ

この雛形には次のものが入っています。

- プロジェクト専用のパッケージ構成
- 仮の音響特徴カタログ
- `data/raw/` を走査する最小 CLI
- ダミーの特徴量テーブル出力
- 簡易レポート生成

今は形だけの実装なので、あとから `librosa` ベースの本実装に差し替えやすい構成を優先しています。

## クイックスタート

```powershell
Set-Location .\audio
$env:PYTHONPATH = "src"
python -m audio_lab
```

生成されるファイル:

- `results/tables/prototype_audio_features.csv`
- `results/reports/prototype_audio_report.md`
